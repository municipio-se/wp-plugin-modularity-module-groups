# Changelog

## 1.0.1 — 2026-10-19

Preserve content-area group backgrounds on the One Page template when global
sidebar widgets are active. That template never renders side columns. Other
templates and stored group metadata retain their existing behavior.

## 1.0.0 — 2026-09-17

First stable release with independent semantic versioning. Preserves the group
editor, grouped rendering and saved row format from development commit 565006d.
The Nora reference accepted drag recovery, sorting, backgrounds, placement
restrictions and save/reload. No activation or data migration is introduced. The
content-specific editor asset identifier remains unchanged.

Publication and Composer distribution checks passed on 2026-09-17.

Documentation status corrected after publication. The immutable 1.0.0 archive
retains the original candidate wording; runtime code and the tag are unchanged.
